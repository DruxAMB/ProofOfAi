# Design source

Adapted from **dope.security** — "Midnight terminal with violet beacons"
https://styles.refero.design/style/e1f18a7e-5af1-46b3-8f89-bce6c78b80d4 (source product: https://dope.security)

## What was taken

- **Generative twilight sky hero** — CSS-layered dusk gradient + light streak, evoking their atmospheric photo without copying assets
- **The boarding-pass card** → "Attestation Pass": CONTENT → BLOCK 677 origin/destination, SEAT/GATE/VALID mono fields, CSS barcode — the flight metaphor doing real product work
- **Flight-route connector** — 01 ●——● 02 node line between NOTARIZE and VERIFY, from their comparison-card pattern
- Italic display serif hero line (GrandSlang → Lora Italic) + stamped mono labels (0.2em tracking)
- Signal Violet `#af50ff` rationed: one filled action (Notarize CTA); lavender `#e1bdff` for small accents
- Frosted top nav `rgba(51,50,72,0.7)` + blur(10px); coordinate-stamp footer ("Fly Direct", "[ ATTESTED ]")
- Shadowless: depth is hairlines + washes only. Radii 6/8/20px + full pills

## Substitutions (license)

- Whyte Inktrap → Inter 300/400 (OFL)
- Whyte Inktrap Mono → JetBrains Mono (OFL)
- GrandSlang → Lora Italic (OFL)
- 19.2px card radius → 20px (extraction artifact, rounded)
- Ash `#6b6b6b` lifted to Steel `#828384` for any text use (3.7:1 fails body contrast; Steel = 5.2:1)
- Near-black canvas `#090909`, near-white primary text `#f7f9fa`, hairline borders `rgba(247,249,250,~0.16)` — never shadows
- **Stamped section headings**: JetBrains Mono uppercase at 0.2em tracking ("boarding pass" voice)
- **Italic display serif** for the one hero line (GrandSlang → Lora Italic substitute)
- **Signal Violet `#af50ff` rationed**: exactly one glow (hero) + one filled action (Notarize). Never text, never borders
- Frosted top nav `rgba(51,50,72,0.7)` + `blur(10px)` — the blur is the design
- Coordinate-stamp footer ("+ proofofai · chain 677 · 0xf201…")
- Radii: 6px controls / 8px buttons / 20px cards / full pills
